# Changelog

One line per change or correction; problem details in `references/pitfalls.md` (#N).

## 0.3.1 — 2026-10-31 (bundled plain-mode styles)

- `assets/plain_reference.docx` / `plain_reference_zh.docx`, generated by
  `scripts/make_plain_reference.py` from pandoc's default reference: Times New Roman / 宋体 body
  12 pt, black bold headings (黑体), tables/captions 10.5 pt, no theme fonts or colours; the zh
  variant indents body paragraphs two characters. `plain_docx.py` picks one by language
  (`--reference-doc` for another); the report records the reference and its SHA-256.
- Layout fixes in plain mode: no indent in cells/pictures/display equations, pictures and tables
  centred, space after tables (#34, #36).
- Verified: 23-page Chinese paper (26/26 equations, 7 tables, none spanning pages), English test
  paper and the eval input built and reviewed page by page.

## 0.3.0 — 2026-10-31 (two inputs: Markdown + optional template)

- Interface reduced to Markdown (required) + template (optional). No template → **plain mode**
  (`plain_docx.py`: pandoc defaults, equation font fixes, grid tables kept together, no alt-text
  captions, completeness checks #32–#34). Template → `resolve_template.ps1` finds the profile by
  the file's SHA-256; none → DOCX copy (host converts `.doc`), probe and page renders prepared,
  exit 2 → `new_journal_profile.md` (#35). `-ProfileName` / `-ProfileDir` still work.
- `make_docx.ps1`: `-TemplatePath`, `-AllowLiteralDollar`; paper config and `-MathEngine cs`
  rejected in plain mode; a page-spanning table is a warning in plain mode (a table taller than a
  page must break), a failure in template mode.
- `tex2omml.py`: run fixes split out (`fix_math_runs`, optional size); `render_pages.py --pages all`.
- New eval `converts-without-template`.
- Verified: plain mode on the 22-page Chinese paper (26/26 equations, 7 tables, 4 pictures) and the
  English test paper, pages reviewed; malformed `$`, missing picture → listed errors;
  `-TemplatePath` with the journal's original `.doc` resolves to its profile and builds; an
  unknown `.doc` template → converted, probed, 11 pages rendered, exit 2; template-mode output
  unchanged (32/32 parts identical to the 0.2.0 build).

## 0.2.0 — 2026-10-31 (generality review)

- Audit found the builder still encoded one paper's/journal's conventions (fixed 8-slot bilingual
  front matter with fixed labels and order, `## 1` body start, 图/表 caption words, 注 notes,
  参考文献/附录 headings, citation-after-文献 rule, `p=` italics, per-table column widths for 7
  tables, exactly four sections, 待填 placeholder, "Table N" caption format, fixed 8 pt sizes).
  All moved to data: `scripts/default_rules.json` ← profile `rules` ← paper `rules` (#9, #10).
- New scripts that turn uncertainty into checked facts: `probe_template.ps1` (#1, #2),
  `validate_profile.ps1` (#7), `probe_host.ps1` + automatic host fallback in `make_docx` (#25).
- All unconvertible formulas reported at once with line numbers (#23); default citation pattern
  accepts spaces (`[1, 2]`); template without an inline picture handled (#8).
- Two case-insensitive-variable bugs found during the refactor and fixed (#15).
- Docs: SKILL.md lists each uncertainty and the script that settles it; `references/rules.md`
  documents every rule key; journal specifics only in `profiles/<name>/profile.md`; the example
  manuscript moved into the profile.
- Verified: archived build reproduced part by part (36/36, `-MathEngine cs`) with the
  conventions now supplied by the profile; an English-only manuscript built on the same template
  through paper overrides alone; `validate_profile` 0 FAIL on the profile and catches a broken
  copy.

## 0.1.0 — 2026-10-31

- Extracted from a manuscript project: builder, LaTeX→OMML converter, native-save script,
  template audit tools, a first journal profile (kept outside the public repository).
- Builder made data-driven: journal-specific text → `profile.json` (#3, #4); paper-specific tweaks
  (title line break, caption parenthetical → note) → `paper_overrides.json`; inputs by parameter
  instead of script-relative paths; single-column defaults without `layout_config.json`;
  revision-folder rule made opt-in (#14).
- New default formula engine: pandoc/texmath (`tex2omml.py`) with font/size/space fixes (#15–#21);
  `cs` engine kept. Compared on the manuscript's 26 formulas: pandoc fixes Σ limits in display
  equations, `\qquad`, upright Δ, Unicode minus; latex2mathml+MML2OMML rejected (#16).
- Host-agnostic native save (`finalize_native.ps1`, from `finalize_with_word.ps1`): WPS default,
  Word optional; WPS story-range loop and missing properties handled (#22–#24).
- `check_runtime.ps1`, one-shot `make_docx.ps1`, minimal example, docs.
- Verified:
  - `-MathEngine cs` with the archived inputs reproduces the archived build
    (`reference_revision/manuscript_working.docx`, DD196E03…) part by part: 36/36 identical.
  - `-MathEngine pandoc`: identical except inside the 26 `m:oMath` elements.
  - `make_docx` end to end via WPS: 223 source lines covered, 11 pages, 12 sections, 7 tables
    (none spanning pages), 26 OMML preserved, 8 PAGE fields updated; pages reviewed.
  - Minimal example builds with no paper config.
